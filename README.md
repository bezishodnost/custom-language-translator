# Custom Language Translator

A simple desktop app made with Python and Tkinter. You can create your own custom language or cipher, save multiple alphabets, and translate text in real time.

## What it can do
* Create your own alphabet with any number of letters, spaces, and punctuation marks
* Save as many languages as you want (everything is stored locally in JSON files)
* Encrypt and decrypt text on the fly (Normal to Cipher and Cipher to Normal)
* Copy the translated result in one click

## Files in this repo
* `Translator.exe` - ready-to-use Windows app (no Python needed, just download and run)
* `translator.py` - full source code if you want to run it via Python or change something

## How to run
If you are on Windows, just download `Translator.exe` from this repo and launch it. Windows might show a SmartScreen warning because the file has no paid certificate, just click "More info" and "Run anyway".

If you want to run from source, make sure you have Python 3 installed and run:
```bash
python translator.py
```
Good luck!
